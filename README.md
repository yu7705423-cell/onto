# 文档合并拆分

一个纯本地的 HTML 小工具：把多个 docx / txt（或 zip、文件夹）合并成**一个** docx 或 txt，方便上传到只允许传单个文件的平台；合并出来的文件再导回来，可以按原文件名拆回一个个文件。

**直接双击打开 `index.html` 即可使用**，不需要联网，所有数据只保存在当前浏览器（IndexedDB）里。白灰配色，右上角可切换深夜模式（默认跟随系统）。

## 功能

界面按手机 App 的习惯设计（参考微信 / QQ / WhatsApp / LINE），电脑上也能用。

- **合并**：选文件、zip（自动解压）、文件夹（电脑上可直接拖进窗口），或者「新建文档」直接写一段须知。
  - 列表像聊天列表：点一下或点右边的笔 = 编辑内容和**批注**；**左滑**置顶、移除；**长按**（电脑上右键）弹出菜单。
  - 「排序」模式：按住右边的把手拖动，或一键按名称 / 类型 / 倒序排。
  - 底部像聊天输入框：填总文件名，点 DOCX/TXT 切换格式，点「合并」先预览，再下载或分享。
- **拆分词**：每个文件开头那一行，可以自定义，比如 `✦ {文件名} ✦`（`{文件名}` 会换成真实文件名）。
  - 合并文件开头默认会写明「拆分词：xxx」，导回来时自动认出来。
  - 认不出来时，输入作者给的拆分词（整句「拆分词：xxx」粘贴也行）就能拆开。
  - 预览页、记录页都有「复制拆分词」，分享文件时一起发给对方。
- **批注**：每条记录、每个文件都能写批注（比如注入顺序）。文件批注会写进合并文件的目录里，拆回来时会恢复。
- **目录**：每次合并和导入都会记一条，点进去是一个个文件，可以编辑、批注、排序、删除、下载。搜索能搜文件名、批注和文档内容。支持导出 / 导入备份。
- **设置**（右上角齿轮）：字体大小（小 / 标准 / 大 / 特大）、浅色 / 深色 / 跟随系统。
- 手机返回键 / 返回手势会关掉当前页面。

## 说明

- 合并时会检查内容里有没有和拆分词长得一样的行，有的话会提示换一个拆分词，避免拆错。
- 旧版本生成的 `<<<<< 文件 1/3 开始 >>>>>` 格式（「经典」）仍然可以拆。
- docx 只提取文字和换行，图片、表格样式、字体格式等不会保留；表格按单元格逐行展开。
- 旧版 `.doc` 不支持，需先另存为 `.docx`。

## 开发

源码在 `src/app.html`，依赖 [JSZip](https://stuk.github.io/jszip/)（`vendor/`，MIT）。修改后运行：

```sh
node build.js
```

会把 JSZip 内联进去，生成单文件 `index.html`。
